# AEUX 1.0.0

## 中文

首个 dreamstring 维护版本，包含配套 Figma 插件与 AE CEP。

- 改善嵌套 Frame / Group、Auto Layout 布局结果的坐标转换，以及旋转、翻转。
- 改善图片边界、大图导出、文字位置和字距、透明度、模糊、阴影、蒙版与裁剪。
- CEP 保留自定义图片目录，增加工程位置（AEP/Source/AEUX）选项。
- 增加导出进度与错误反馈；支持的图层优先保留可编辑。
- 不包含实验性的柔光辅助层运算方案；复杂外观仍可能使用预合成或栅格化。

下载 AEUX-1.0.0.zip，包含 CEP/AEUX、Figma、安装说明和许可证。
CEP 用户目录：%APPDATA%\Adobe\CEP\extensions。Figma 从 Figma/manifest.json 导入。
先退出 AE 并移走旧 AEUX，避免重复扩展。详细步骤见 README。

## English

First community-maintained release by dreamstring, pairing the Figma plugin and AE CEP.

- Improved nested frame/group transforms, resolved Auto Layout placement, rotation and flips.
- Improved raster bounds/large exports, text placement/tracking, opacity, blur, shadows, masks and clipping.
- Custom image output path plus project-relative AEP/Source/AEUX directory.
- Export progress and error feedback. Editable layers are preferred where representable.
- Experimental Soft Light helper graphs are excluded. Complex appearances can require precomps or raster fallback.

Download AEUX-1.0.0.zip. Copy CEP/AEUX into %APPDATA%\Adobe\CEP\extensions and import Figma/manifest.json in Figma desktop. Quit AE and remove duplicate older AEUX installations first. See README for unsigned CEP setup and full instructions.

Fonts and some background-blur/fill-stroke blending remain compatibility limitations. Tested workflows focus on Windows AE 23.5 and Figma 126.10.7, not every host version.

Use the named ZIP asset, not GitHub's automatic Source code download. The release contains the accepted paired runtime; full repository application-source synchronization is tracked separately.
