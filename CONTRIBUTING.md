# Contributing

Use https://github.com/dreamstring/AEUX for issues and pull requests.
Provide a minimal synthetic reproduction, expected output and nested hierarchy.
Do not include credentials or private design files.

Prefer shared conversion functions over layer-name workarounds. Keep editable
output as the default and explain additional precomps or raster fallbacks.
Run npm test. Desktop integration changes also need paired Figma/CEP acceptance
and recursive hierarchy inspection. Preserve Apache 2.0 and upstream notices.
